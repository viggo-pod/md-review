# 云记账 SaaS 产品需求文档（PRD）

> 版本：v1.2 | 状态：评审中 | 产品负责人：张伟

## 1. 产品概述

云记账是一款面向中小企业的在线财务记账产品，支持多人协作、自动分类、报表导出。本产品需要支持 2 亿注册用户，月活用户 5000 万。

## 3. 用户故事

- 作为会计，我希望凭证能够自动分类，以便减少手动录入时间
- 作为老板，我希望每周收到经营报表推送，以便及时掌握现金流
- 作为财务总监，我希望能够给团队成员分配不同的查看权限

## 4. 核心业务规则

### 4.1 会员等级

VIP 会员可享受无限凭证录入次数，普通会员每月限制 500 条凭证。VIP 等级分为 VIP1、VIP2、VIP3 三档，VIP3 可享受专属客服。

### 4.2 自动分类规则

系统根据凭证摘要关键词自动分类，置信度低于 80% 的凭证进入待人工确认队列。分类置信度 = 匹配关键词数 / 总关键词数 × 100%。

### 4.3 退款流程

用户发起退款申请 → 系统校验订单状态 → 财务审核（金额超过 500 元的退款单直接自动通过）→ 原路退回。退款状态变化：申请中 → 审核中 → 已退款。

## 5. 性能指标

| 指标 | 目标值 |
|---|---|
| 登录响应时间 | P95 < 800ms |
| 凭证保存响应时间 | P95 < 1s |
| 并发支持 | 1000 并发用户 |
| 报表导出时间 | 10 万条数据 < 30 秒 |

注：生产环境压测目标为 5000 并发，架构设计容量以此为准。

## 6. 数据分析指标

- 用户留存率 = 当月活跃且次月仍活跃的用户数 / 当月活跃用户数 × 100%
- 示例：当月活跃 1000 人，其中 600 人下月仍活跃，留存率 = 30% ✓
- 付费转化率 = 付费用户数 / 注册用户数 × 100%

## 7. 非功能需求

- 可用性：99.9%（每年停机不超过 8.76 小时）
- 数据备份：每日全量备份 + 每小时增量备份，数据保留 90 天
- 合规：通过等保三级认证
