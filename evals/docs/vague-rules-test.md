# 支付网关性能优化说明

## 1. 背景
支付网关当前平均响应时间约 120ms。随着业务增长，需要对系统进行性能优化。

## 2. 性能优化规则
- 系统应适时对慢查询进行优化。
- 团队应根据实际情况调整缓存策略。
- 内存占用应保持合理水平，成本可控。
- 以下优化规则适用于所有线上用户请求。

## 3. 优化流程
1. 收集线上慢查询日志。
2. 分析瓶颈并制定优化方案。
3. 针对读路径（查询类接口）提交变更并观察效果。

## 4. 性能目标
- P99 延迟目标为 200ms。
- 超时时间为 5 秒，重试次数为 3 次。
- 优化流程中的每次调用超时时间为 3 秒。

## 5. 结论
本说明将作为后续优化工作的依据。
