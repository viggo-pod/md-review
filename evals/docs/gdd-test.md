# 《星途跳跃》游戏设计文档（GDD）

> 版本：v0.9 | 状态：设计评审中 | 策划：李娜

## 1. 游戏概述

《星途跳跃》是一款竖屏 2D 平台跳跃手游，玩家操控宇航员在星球间跳跃前进，收集星尘并躲避障碍。目标用户为 12-25 岁休闲玩家。

## 2. 核心玩法

### 2.1 核心循环

玩家在关卡中跳跃收集星尘 → 星尘用于购买强化道具 → 强化道具帮助通关更难的关卡 → 通关获得更多星尘。连续跳跃命中星尘可触发连击，连击数提升星尘倍率。

### 2.2 核心机制列表

| 机制 | 描述 |
|---|---|
| 跳跃 | 单跳 + 二段跳，长按跳得更高 |
| 星尘收集 | 触碰即收集，连击可翻倍 |
| 障碍躲避 | 尖刺、移动平台、激光 |
| 强化道具 | 磁铁、护盾、双倍星尘 |

## 3. 数值设计

### 3.1 角色属性

| 属性 | 基础值 |
|---|---|
| 移动速度 | 5 m/s |
| 跳跃高度 | 3 m |
| 生命值 | 3 点 |
| 无敌时间 | 1 秒 |

### 3.2 伤害公式

角色受到的伤害 = 障碍物攻击力 - 角色防御力。

示例：攻击力 10，防御力 5，实际伤害 = 4 点。

### 3.3 暴击公式

暴击伤害 = 基础伤害 × 暴击倍率。暴击倍率由关卡难度决定，暴击率为 10%。

### 3.4 关卡移动速度

后期关卡角色移动速度提升至 300 px/s，跳跃高度不变。

## 4. 关卡设计

### 4.1 关卡列表

| 关卡 | 主题 | 难度 | 星尘目标 |
|---|---|---|---|
| 1-1 | 新手村 | 简单 | 100 |
| 1-2 | 星云带 | 简单 | 150 |
| 2-1 | 陨石区 | 中等 | 200 |
| 3-1 | 黑洞边缘 | 困难 | 350 |

### 4.2 关卡解锁规则

- 通关当前关卡解锁下一关
- 收集「星尘钥匙」可提前解锁后续关卡
- 关卡 3-1 需要收集 3 把星尘钥匙

## 5. 道具系统

| 道具 | 效果 | 星尘价格 |
|---|---|---|
| 磁铁 | 自动吸引附近星尘 | 50 |
| 护盾 | 抵挡一次伤害 | 80 |
| 双倍星尘 | 本关星尘翻倍 | 120 |

### 5.1 道具获取

「磁铁」道具可通过完成关卡 1-2 全星通关奖励获得。

## 6. 美术与音频

- 画风：低多边形 + 霓虹渐变
- 主角动画：跳跃/下落/受伤/胜利 4 套
- 音频：背景音乐 2 首 + 音效 20 个

## 7. 社交系统

- 好友排行：按通关总分排名
- 分享成就：通关后分享截图到社交平台

## 8. 商业化

- 内购：星尘礼包（6 元 / 30 元 / 68 元三档）
- 广告：关卡失败后观看广告复活一次

## 9. 验收标准

- 核心循环可玩：从收集星尘到购买道具全流程可完成
- 关卡 1-1 通关时间控制在 2-5 分钟
- 游戏帧率稳定在 60 FPS（低端机 30 FPS）
