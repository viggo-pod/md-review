# 概念设计文档：《青瓷》——水墨解谜游戏（Concept）

## 创意概述

《青瓷》是一款以宋代瓷器修复为主题的水墨风解谜游戏。玩家扮演修复师，通过拼合碎片、调色补釉来复原古瓷，并解开瓷器背后的历史谜题。创意可一句话讲清，且具备独特的美学辨识度。

## 创新点

- 以「瓷器修复」这一冷门题材切入
- 水墨晕染动态渲染
- 碎片拼合与历史叙事双线并行

## 玩法原型

核心玩法原型已完成：玩家拖动碎片到对应位置，碎片吸附时触发水墨动画。调色系统原型尚未验证手感。

## 情感目标

让玩家在修复过程中获得「化残为美」的平静与成就感。

## 市场潜力

休闲解谜市场增长稳定。手游用户中偏文艺审美的玩家群体规模可观，具体市场规模与增速未给出数据支撑。
